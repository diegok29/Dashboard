# 📈 Admin Dashboard — Painel de Controle Analítico

Um **Dashboard Administrador** interativo e responsivo desenvolvido com **HTML5**, **CSS3** e **JavaScript Vanilla**. O projeto foi estruturado para visualização de métricas, indicadores chave de desempenho (KPIs), tabelas de dados e controle dinâmico de elementos de interface.

---

## 🌐 Demo Online

Acesse o projeto publicado: https://diegok29.github.io/Dashboard/

---

## 🚀 Funcionalidades

- **Painel de Indicadores (KPIs):** Exibição de estatísticas e cartões de resumo com métricas do sistema.
- **Tabelas de Dados:** Listagem organizada de informações com opções de manipulação visual.
- **Navegação Lateral (Sidebar):** Menu de navegação dinâmico e colapsável para alternar entre visões.
- **Layout Responsivo:** Adaptação fluida para dispositivos móveis, tablets e monitores widescreen.
- **Interface Otimizada:** Design limpo focado na experiência do usuário (UX) e facilidade de leitura dos dados.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica para montagem da grid e seções do painel.
- **CSS3:** Layouts avançados com **CSS Grid** e **Flexbox**, estilização de componentes e transições suaves.
- **JavaScript (ES6+):** Manipulação do DOM, controle de eventos do menu e dinamização dos dados.
